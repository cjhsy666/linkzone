# 插件市场

插件市场用于浏览、安装和管理插件。

## 使用方法

### 添加仓库

在管理后台 → 插件市场 → 仓库管理中添加仓库：

- **名称**：仓库显示名称
- **URL**：仓库地址（`https://...` 或加密地址 `lzm://...`）
- **Token**（可选）：私有仓库可能需要

添加后点击"测试连接"验证是否可用。

### 浏览和安装

1. 在插件市场页面浏览或搜索插件
2. 点击"安装"
3. 重启运行时生效

### 更新插件

已安装插件有新版本时会显示"有更新"标记，点击"更新"即可升级。

### 卸载插件

在已安装列表中选择插件，点击"删除"。

## 付费插件授权

部分插件需要授权码才能使用。

### 用户操作

1. 安装付费插件后，发送插件命令会提示"需要授权"
2. 获取授权码后，发送 `激活 <授权码>` 激活插件
3. 激活后即可正常使用

> 授权码由插件开发者提供，通常通过购买或申请获得。

### 插件包授权

多个插件可以组成插件包，共用一个授权码：
- 购买插件包后，激活任意一个插件即可解锁包内所有插件
- 解绑任意插件会清除包内所有插件的授权

### 开发者配置

在插件元信息中设置 `license_config` 声明付费模式：

```javascript
// Node.js
metadata: {
    name: 'my-plugin',
    license_config: {
        paid: true,           // 是否付费
        price: '10元/月',     // 价格描述
        bundle_id: 'my-suite' // 插件包标识（可选）
    }
}
```

```python
# Python
metadata = {
    "name": "my-plugin",
    "license_config": {
        "paid": True,
        "price": "10元/月",
        "bundle_id": "my-suite"
    }
}
```

## 发布插件

在插件元信息中设置 `@public true` 即可公开发布：

```javascript
// Node.js
/**
 * @public true
 */
```

```python
# Python
# @public true
```
