# 返利服务

电商平台的商品转链和返利功能。用户发送电商链接，机器人自动转为推广链接，购买后获得返利。支持淘宝、京东、拼多多。

## 配置步骤

### 1. 获取平台凭证

| 平台 | 需要的凭证 | 去哪获取 |
|------|-----------|----------|
| 淘宝/天猫 | 折淘客 AppKey + Sid，淘宝 PID | [折淘客](https://www.zhetaoke.com/) 申请 AppKey；[淘宝联盟](https://pub.alimama.com/) 创建推广位获取 PID |
| 京东 | UnionID + Key | [京东联盟](https://union.jd.com/) 开放平台申请 |
| 拼多多 | ClientID + ClientSecret + PID | [多多进宝](https://jinbao.pinduoduo.com/) 开放平台申请 |

### 2. 填写配置

管理后台 → 返利管理 → 平台配置，填入对应平台的凭证。

### 3. 启用插件

确保以下插件已启用：
- `rebate` — 自动转链
- `rebate_user` — 用户查询
- `rebate_admin` — 管理功能

## 用户命令

| 命令 | 说明 |
|------|------|
| `个人信息` | 查看账户信息 |
| `余额` | 查看余额和累计收入 |
| `绑定支付宝 账号` | 绑定提现账号 |
| `提现 金额` | 提现到支付宝 |
| `我的订单` | 查看订单记录 |
| `兑换积分 金额` | 余额换积分 |

## 管理员命令

| 命令 | 说明 |
|------|------|
| `提现列表` | 查看待处理提现 |
| `处理提现` | 审批提现 |
| `添加余额` | 给用户充值 |
| `订单统计` | 查看订单统计 |

## 订单追踪

管理后台 → 返利管理 → 订单追踪中配置：
- 启用各平台订单追踪
- 设置拉取间隔（默认每 30 分钟）
- 配置 API 凭证（与转链凭证相同）

## 转链样式

在返利插件配置中设置 `display.style`：

| 样式 | 效果 |
|------|------|
| `simple` | 简洁：仅显示价格和返利 |
| `emoji` | 默认：带图标，显示完整信息 |
| `detailed` | 详细：显示平台、店铺、销量等 |
