# 返利服务

返利服务提供电商平台的商品转链、佣金查询、订单追踪和返利计算功能，支持淘宝、京东、拼多多三大平台。

## 核心功能

| 功能 | 说明 |
|------|------|
| 智能转链 | 自动识别消息中的电商链接，转换为推广链接 |
| 商品查询 | 查询商品详情、优惠券、佣金信息 |
| 返利计算 | 根据会员等级自动计算买家返利、上级佣金、代理佣金 |
| 订单追踪 | 自动拉取京东/淘宝/拼多多订单，追踪佣金结算 |
| 批量转链 | 一条消息中包含多个链接时批量转换 |
| 保留原文 | 转链后保留原始文本，仅替换链接部分 |

## 支持平台

| 平台 | 转链方式 | 订单追踪 |
|------|---------|---------|
| 淘宝/天猫 | 大淘客 API | 支持 |
| 京东 | 京东联盟 API | 支持 |
| 拼多多 | 多多进宝 API | 支持 |

## 配置

### 平台配置

在管理后台 → 返利管理中配置各平台参数：

**淘宝（大淘客）**
- AppKey、AppSecret
- PID（推广位ID）

**京东**
- UnionID、Key
- AppID、AppKey

**拼多多**
- ClientID、ClientSecret
- AccessToken

### 会员组与等级

返利计算基于会员组体系，每个会员组包含多个等级，不同等级对应不同的佣金比例：

| 分配对象 | 说明 |
|---------|------|
| 买家返利 | 购买者获得的返利比例 |
| 上级佣金 | 邀请人获得的佣金比例 |
| 代理佣金 | 代理获得的佣金比例 |
| 合伙人佣金 | 合伙人获得的佣金比例 |

在管理后台 → 返利管理 → 会员组中创建和管理会员组与等级。

### 阶级规则

阶级规则根据佣金金额区间自动匹配返利比例，实现阶梯式返利。

在管理后台 → 返利管理 → 阶级规则中配置。

### 订单追踪配置

在管理后台 → 返利管理 → 订单追踪中配置：

- 启用/禁用各平台追踪
- 设置拉取间隔（分钟）
- 设置每日定时拉取时间
- 配置各平台 API 凭证

## 使用方式

### 自动转链

当用户在群组中发送包含电商链接的消息时，机器人会自动识别并转链，返回带有返利信息的推广链接。

转链结果包含：
- 商品名称和图片
- 原价、券后价、优惠券金额
- 预计返利金额
- 推广链接

### 管理命令

返利管理插件提供以下命令（需要管理员权限）：

| 命令 | 说明 |
|------|------|
| 添加阶级规则 | 添加佣金阶梯规则 |
| 查看阶级规则 | 查看所有阶级规则 |
| 删除阶级规则 | 删除指定阶级规则 |
| 添加会员组 | 创建新的会员组 |
| 添加会员等级 | 在会员组中添加等级 |
| 查看会员组 | 查看所有会员组 |
| 删除会员组 | 删除指定会员组 |
| 提现列表 | 查看待处理提现申请 |
| 处理提现 | 审批提现申请 |
| 添加余额 | 为用户添加余额 |
| 设置管理员 | 设置返利管理员 |
| 订单统计 | 查看订单统计数据 |
| 提现统计 | 查看提现统计数据 |
| 返利健康 | 检查返利服务状态 |

## 返利角色

| 角色 | 说明 |
|------|------|
| Buyer（买家） | 普通用户，购买商品获得返利 |
| Agent（代理） | 管理下级买家，获得代理佣金 |
| Partner（合伙人） | 最高级别，获得合伙人佣金 |

## 消息样式

转链回复支持三种样式，在插件配置中设置：

| 样式 | 说明 |
|------|------|
| simple | 简洁模式，仅显示价格和返利 |
| emoji | 默认模式，带 emoji 图标，显示完整信息 |
| detailed | 详细模式，显示平台、店铺、销量等全部信息 |
