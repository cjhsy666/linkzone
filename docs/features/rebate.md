# 返利服务

返利服务提供电商平台的商品转链和返利功能。用户在群组中发送电商链接，机器人自动转换为推广链接，购买后可获得返利。支持淘宝、京东、拼多多三大平台。

## 快速开始

### 1. 配置平台凭证

在管理后台 → 返利管理 → 平台配置中，填写你要使用的电商平台 API 凭证。

至少配置一个平台的转链服务：

| 平台 | 必填配置 | 说明 |
|------|---------|------|
| 淘宝/天猫 | 折淘客 AppKey + Sid，淘宝 PID | 折淘客提供转链 API，PID 为你的淘宝推广位 ID |
| 京东 | UnionID + Key | 京东联盟账号的联盟 ID 和 API Key |
| 拼多多 | ClientID + ClientSecret + PID | 多多进宝开放平台凭证 |

还可以配置大淘客（Dataoke）或京推推（Jingtuitui）作为备用转链服务。

### 2. 启用返利插件

在管理后台 → 插件管理中，确保以下插件已启用：

- **返利转链插件**（rebate_plugin）— 自动识别电商链接并转链
- **用户返利插件**（rebate_user_plugin）— 用户查询余额、提现等
- **返利管理插件**（rebate_admin_plugin）— 管理员管理返利系统

### 3. 开始使用

配置完成后，用户在群组中发送包含电商链接的消息，机器人会自动转链并回复返利信息。

## 用户操作

普通用户可以通过发送命令来管理自己的返利账户：

### 账户管理

| 命令 | 说明 |
|------|------|
| `个人信息` | 查看用户名、ID、余额、会员等级、绑定平台 |
| `余额` | 查看当前余额、冻结金额、累计收入 |
| `修改用户名 新名` | 修改用户名 |
| `绑定支付宝 账号` | 绑定支付宝账号（提现必需） |
| `查看支付宝` | 查看已绑定的支付宝 |
| `绑定姓名 真实姓名` | 绑定真实姓名 |
| `查看姓名` | 查看已绑定的姓名 |

### 提现

| 命令 | 说明 |
|------|------|
| `提现 金额` | 提现到已绑定的支付宝，如 `提现 10` |
| `提现 金额 方式 账号` | 指定提现方式和账号，如 `提现 10 支付宝 xxx@alipay.com` |
| `我的提现` | 查看提现记录和状态 |

提现说明：
- 最低提现金额默认 1 元，可在插件配置中调整
- 提现申请提交后，需管理员审批
- 预计 1-3 个工作日到账

### 订单与积分

| 命令 | 说明 |
|------|------|
| `我的订单` | 查看最近的订单记录 |
| `兑换积分 金额` | 将余额兑换为积分，如 `兑换积分 5` |

积分兑换比例默认 1 元 = 100 积分，可在插件配置中调整。

## 管理员操作

管理员（权限等级 6 及以上）可使用以下命令管理返利系统：

### 会员组管理

会员组用于定义不同用户的返利比例。每个会员组包含多个等级，不同等级对应不同的佣金分配。

| 命令 | 说明 |
|------|------|
| `添加会员组` | 创建新的会员组 |
| `添加会员等级` | 在会员组中添加等级 |
| `查看会员组` | 查看所有会员组和等级 |
| `删除会员组` | 删除指定会员组 |

### 阶级规则

阶级规则根据佣金金额区间自动匹配返利比例，实现阶梯式返利。

| 命令 | 说明 |
|------|------|
| `添加阶级规则` | 添加佣金阶梯规则 |
| `查看阶级规则` | 查看所有阶级规则 |
| `删除阶级规则` | 删除指定阶级规则 |

### 提现与统计

| 命令 | 说明 |
|------|------|
| `提现列表` | 查看待处理的提现申请 |
| `处理提现` | 审批提现申请（通过/拒绝） |
| `添加余额` | 为用户手动添加余额 |
| `设置管理员` | 设置返利管理员 |
| `订单统计` | 查看订单统计数据 |
| `提现统计` | 查看提现统计数据 |
| `返利健康` | 检查返利服务运行状态 |

## 返利角色

| 角色 | 说明 |
|------|------|
| Buyer（买家） | 普通用户，购买商品获得返利 |
| Agent（代理） | 管理下级买家，获得代理佣金 |
| Partner（合伙人） | 最高级别，获得合伙人佣金 |

佣金分配流程：商品佣金 → 买家返利 + 上级佣金 + 代理佣金 + 合伙人佣金，具体比例由会员组和阶级规则决定。

## 订单追踪

返利服务自动拉取各平台订单，追踪佣金结算状态。

在管理后台 → 返利管理 → 订单追踪中配置：

- 启用/禁用各平台订单追踪
- 设置拉取间隔（分钟）
- 设置每日定时拉取时间
- 配置各平台 API 凭证

## 转链回复样式

转链回复支持三种样式，在返利转链插件的配置中设置 `display.style`：

| 样式 | 说明 |
|------|------|
| `simple` | 简洁模式，仅显示价格和返利 |
| `emoji` | 默认模式，带 emoji 图标，显示完整信息 |
| `detailed` | 详细模式，显示平台、店铺、销量等全部信息 |

## 支持的链接格式

机器人能自动识别以下格式的电商链接：

**淘宝/天猫**
- `https://item.taobao.com/item.htm?id=xxx`
- `https://m.tb.cn/h.xxx`
- 淘口令 `￥xxx￥`
- 分享卡片（微信中的淘宝分享）

**京东**
- `https://item.jd.com/xxx`
- `https://u.jd.com/xxx`
- `https://3.cn/xxx`

**拼多多**
- `https://mobile.yangkeduo.com/goods.html?goods_id=xxx`
- `https://p.pinduoduo.com/xxx`
