# 用户 API

## 用户管理

### 获取用户列表

```
GET /admin/users
```

### 获取用户详情

```
GET /admin/users/{id}
```

### 更新用户信息

```
PUT /admin/users/{id}
```

### 删除用户

```
DELETE /admin/users/{id}
```

### 获取用户画像

```
GET /admin/users/{id}/profile
```

### 更新用户画像

```
PUT /admin/users/{id}/profile
```
